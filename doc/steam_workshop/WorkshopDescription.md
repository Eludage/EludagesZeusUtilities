[h1]Eludages Zeus Utilities[/h1]

[b]Eludages Zeus Utilities[/b] is a client-side mod for Arma 3 that adds custom Zeus modules to support and streamline Zeus / game-master workflows, built on top of the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=1779063631]ZEN (Zeus Enhanced)[/url] framework.

[h2]Status[/h2]

This mod is in early development. It currently ships a single test module used to verify the module pipeline works correctly — more Zeus modules are planned and will be added over time.

[h2]Features[/h2]

[list]
[*][b]Working Test[/b] — a placeholder module under the "Eludages Zeus Utilities" category that shows a confirmation hint. Used to validate the mod loads and registers correctly with ZEN.
[/list]

[h2]Installation[/h2]

[olist]
[*]Subscribe to the mod on Steam Workshop
[*]Subscribe to and enable [b]ZEN (Zeus Enhanced)[/b] and [b]CBA_A3[/b] as well
[*]Enable all three in the Arma 3 Launcher
[*]Launch Arma 3 and start or join a mission as Zeus
[/olist]

[b]Requirements:[/b]
[list]
[*]ZEN (Zeus Enhanced)
[*]CBA_A3
[/list]

[b]Usage:[/b]
[list]
[*]As Zeus, open the [b]Modules[/b] list
[*]Look for the [b]Eludages Zeus Utilities[/b] category
[*]Click a module to run it immediately — no map placement needed
[/list]
